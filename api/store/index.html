    store¶

    import "github.com/vinayhpandya/rediska/store"

    Package store holds Rediska's data: an in-memory map from keys to values, with expiry, memory accounting and eviction (LRU or LFU).

    Values are kept in compact encodings, as in Redis: integers as numbers, strings as SDS, HyperLogLogs as sketches (see Encoding).

    A Store is not safe for concurrent use. The server only touches Default from its single dispatch worker goroutine.

    Constants¶

    LRU clock constants. The clock is a 24-bit value that ticks once per second and wraps back to zero roughly every 194 days, mirroring Redis.

    const (
    LRUClockMax        = (1 << 24) - 1 // 16777215
    LRUClockResolution = 1000          // milliseconds per tick (1 second)
    EvictionPoolSize   = 16            // candidates kept across eviction cycles

)

    LFU reuses the same 24-bit `entry.lru` field that LRU uses, exactly like real Redis reuses its `robj.lru:24` bitfield. The two policies are never active on the same key at the same time (maxmemory-policy is global), so no extra struct field is needed:

    bits 8-23 (16 bits): ldt  -- last-decay time, in minutes, wraps ~45 days
bits 0-7  (8 bits):  counter -- logarithmic access counter, 0-255

    const (
    LFUInitVal uint8 = 5 // starting counter for a freshly written key

)

    Variables¶

    LFULogFactor and LFUDecayTime are runtime-tunable (unlike LFUInitVal, which real Redis also keeps fixed). They default to Redis's own defaults and are overridden via SetLFUParams, called from main.go once config flags are parsed.

    var (
    LFULogFactor uint32 = 10 // higher = slower counter growth (config: lfu-log-factor)
    LFUDecayTime uint32 = 1  // minutes per decay step (config: lfu-decay-time)
)

    Default is the global store instance. Never access this directly — always go through the command worker.

    var Default = New()

    ErrNotHLL is returned when a HyperLogLog command is used on a key that holds some other kind of value. The text matches Redis's reply.

    var ErrNotHLL = errors.New("WRONGTYPE Key is not a valid HyperLogLog string value.")

    KeyspaceStat holds the counters INFO keyspace reports, one map per database (only database 0 is used). Only "keys" is kept up to date so far; "expires" and "avg_ttl" are read by INFO but always 0.

    var KeyspaceStat [4]map[string]int

    func SetLFUParams¶

    func SetLFUParams(logFactor, decayTime int)

    SetLFUParams sets how LFU counters grow and decay, from the --lfu-log-factor and --lfu-decay-time flags. Out-of-range values (a negative logFactor, or decayTime below 1) leave the current setting.

    func UpdateDbStat¶

    func UpdateDbStat(num int, metric string, value int)

    UpdateDbStat adds value (which may be negative) to the counter metric of database num.

    type Encoding¶

    Encoding says how a value is stored in memory. OBJECT ENCODING reports it, using the same names as Redis.

    type Encoding int


    const (
    // EncodingINT stores a string that is a valid 64-bit integer as a number.
    EncodingINT Encoding = iota
    // EncodingEMBSTR is a short string (44 bytes or less).
    EncodingEMBSTR
    // EncodingRAW is a longer string, or any string that has been changed
    // by APPEND.
    EncodingRAW
    // EncodingHLL is a HyperLogLog, created by PFADD or PFMERGE.
    EncodingHLL
)

    type Store¶

    Store is not thread-safe. All access must go through the single command worker in server.go.

    type Store struct {
    // contains filtered or unexported fields
}

    func New¶

    func New() *Store

    New returns an empty Store using the noeviction policy.

    func (*Store) Append¶

    func (s *Store) Append(key, value string) int64

    Append implements Redis's APPEND: creates the key if it doesn't exist (identical to a SET with no TTL), otherwise appends to the existing value. An INT-encoded key is converted to its string form first and becomes RAW-encoded afterward — same as real Redis. Returns the new total length, matching Redis's APPEND reply.

    func (*Store) CountKeysInSlot¶

    func (s *Store) CountKeysInSlot(slot int) int

    CountKeysInSlot returns how many keys this store holds in slot.

    func (*Store) Delete¶

    func (s *Store) Delete(keys ...string) int64

    Delete removes keys and returns how many of them existed. Keys that had already expired are removed too, but not counted, as in Redis.

    func (*Store) DeleteExpired¶

    func (s *Store) DeleteExpired() int

    DeleteExpired does one round of active expiry: it checks up to 20 keys that have an expiry, picked in Go's random map order, removes those that have expired, and returns how many it removed. The server runs it every 100 ms and repeats while a round still finds 5 or more expired keys.

    func (*Store) EnableSlotIndex¶

    func (s *Store) EnableSlotIndex()

    EnableSlotIndex turns the index on. Called once at startup in cluster mode.

    func (*Store) Get¶

    func (s *Store) Get(key string) (string, bool)

    Get returns key's value as a string, and whether the key exists. An expired key is removed and reported as missing. It counts as an access for LRU/LFU. A key holding a HyperLogLog is also reported as missing, whereas real Redis would return its raw bytes.

    func (*Store) GetEncoding¶

    func (s *Store) GetEncoding(key string) (Encoding, bool)

    GetEncoding is a metadata read (used by OBJECT ENCODING) and deliberately does NOT bump recency — inspecting a key shouldn't make it look hot.

    func (*Store) GetFreq¶

    func (s *Store) GetFreq(key string) (freq uint8, ok bool, policyOK bool)

    GetFreq returns a key's LFU counter (used by OBJECT FREQ), same as real Redis. It's a metadata read and does NOT bump recency. ok is false if the key doesn't exist, and policyOK is false if the active policy isn't an LFU policy -- callers should surface that as a distinct error, mirroring Redis's "An LFU maxmemory policy is not selected" response.

    func (*Store) GetInt¶

    func (s *Store) GetInt(key string) (int64, bool, error, time.Time)

    GetInt returns key's value as an integer, for commands like INCR. The results are the value, whether the key exists, an error if it exists but doesn't hold an integer, and the key's expiry time (zero if none). It counts as an access for LRU/LFU.

    func (*Store) KeyCount¶

    func (s *Store) KeyCount() int

    KeyCount returns the number of keys currently in the store, including any that are logically expired but not yet removed.

    func (*Store) KeysInSlot¶

    func (s *Store) KeysInSlot(slot, count int) []string

    KeysInSlot returns up to count keys from slot, in no particular order.

    func (*Store) OverMemory¶

    func (s *Store) OverMemory(maxBytes int64) bool

    OverMemory reports whether the store is above the byte limit.

    func (*Store) PFAdd¶

    func (s *Store) PFAdd(key string, values ...string) (changed bool, err error)

    PFAdd adds values to the HyperLogLog at key, creating it if needed. It reports whether anything changed: creating the key counts as a change, even with no values, as in Redis. If key holds some other kind of value, PFAdd changes nothing and returns ErrNotHLL.

    func (*Store) PFCount¶

    func (s *Store) PFCount(key string) int64

    PFCount returns the estimated number of distinct values in the HyperLogLog at key, or 0 if key doesn't exist or isn't a HyperLogLog.

    func (*Store) PFMerge¶

    func (s *Store) PFMerge(dest string, sources ...string)

    PFMerge stores in dest the union of the HyperLogLogs at dest and every source key. Missing keys and keys of other types are ignored. dest loses any expiry it had.

    func (*Store) PerformEvictions¶

    func (s *Store) PerformEvictions(samples int, maxBytes int64)

    PerformEvictions frees keys until the store is back under maxBytes. It runs only inside the single command worker, so it needs no locks.

    func (*Store) Set¶

    func (s *Store) Set(key, value string, ttl time.Duration)

    Set stores value under key, replacing any old value and its expiry. If ttl is greater than zero the key expires after ttl; otherwise it never expires. The value is stored as an integer if it parses as one, and as a string otherwise.

    func (*Store) SetPolicy¶

    func (s *Store) SetPolicy(policy string)

    SetPolicy sets the maxmemory policy, which decides how keys are evicted and whether keys track recency (LRU) or frequency (LFU). It is called once at startup.

    func (*Store) TTL¶

    func (s *Store) TTL(key string) int64

    TTL is a metadata read and does NOT bump recency, matching Redis.

    func (*Store) UsedMemory¶

    func (s *Store) UsedMemory() int64

    UsedMemory returns the store's estimate of the memory its keys and values use, in bytes. It is what --maxmemory is compared against.
